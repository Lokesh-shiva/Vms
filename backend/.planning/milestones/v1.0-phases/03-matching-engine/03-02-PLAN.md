# Plan 02: Stateless Engine Webhook & Trigger

<objective>
Expose a secure REST endpoint (`POST /engine/trigger`) that runs the MatchEngineService grouping algorithm. This keeps the FastAPI service stateless so that an external cron system (e.g. AWS EventBridge, Vercel Cron, systemd timer) can orchestrate it consistently.
</objective>

<requirements>
- MATCH-01
</requirements>

<tasks>
  <task>
    <description>Create match_engine_routes.py and trigger endpoint</description>
    <read_first>
      - modules/match/controller/match_engine_routes.py (create this)
      - modules/match/service/match_engine_service.py
    </read_first>
    <action>
      Create `modules/match/controller/match_engine_routes.py`.
      1. Define an APIRouter prefixed `/engine`.
      2. Add a `POST /trigger` route (synchronous/async handler block) calling `match_engine_service.process_matching_cycle()`.
      3. For v1: Protect the endpoint lightly using a predefined secret header (e.g. `X-Cron-Secret`). Compare it to `os.getenv("CRON_SECRET", "dev-secret")`.
      4. If the header mismatches, return `403 Forbidden`.
      5. Return a simple JSON `{"status": "ok", "matches_created": N}`. 
    </action>
    <acceptance_criteria>
      - `match_engine_routes.py` has `APIRouter`.
      - Contains `POST /trigger` endpoint.
      - Requires `X-Cron-Secret` header or returns 403.
      - Returns integer count of `matches_created`.
    </acceptance_criteria>
  </task>

  <task>
    <description>Register APIRouter in main.py</description>
    <read_first>
      - main.py
      - modules/match/controller/match_engine_routes.py
    </read_first>
    <action>
      Register the new `engine_router` from `match_engine_routes.py` under the FastAPI `app` in `main.py`.
      1. Add `from modules.match.controller.match_engine_routes import router as engine_router`
      2. Append `app.include_router(engine_router)` alongside `matchmaking_router`.
    </action>
    <acceptance_criteria>
      - `main.py` imports `engine_router`.
      - `app.include_router(engine_router)` is present.
    </acceptance_criteria>
  </task>
</tasks>

<must_haves>
- Uses `X-Cron-Secret` to prevent random clients from triggering matching loops.
- Avoids stateful memory loops.
</must_haves>
