## Objective

The matchmaking controller reads `current_user.get("region_id")` to validate the user's region
before queuing. However, the `users` table has no `region_id` column — it was assumed in Phase 2
planning but never added. This makes ALL queue join attempts fail with HTTP 400.

Fix:
1. Add `region_id = Column(Integer, ForeignKey("locations.id"), nullable=True)` to the User model
2. Update `User.to_dict()` to expose `region_id`
3. Run `ALTER TABLE users ADD COLUMN` on the live Neon PostgreSQL database
4. Verify the full queue flow works end-to-end

---

## Context

- **User model**: `modules/user/model/user_model.py` — currently missing region_id
- **User repository**: `modules/user/repository/user_repository.py` — `update()` already supports
  generic field updates via `setattr`, so it will handle `region_id` after model is updated
- **Auth dependency**: `modules/auth/dependencies/auth_dependencies.py` — calls
  `user_repository.find_by_id(user_id)` which calls `user.to_dict()`. Once `to_dict()` includes
  `region_id`, the controller will receive it.
- **DB**: Neon PostgreSQL — `create_all` only creates new tables, NOT new columns on existing
  tables. Must run raw `ALTER TABLE` to add the column.
- **Location model table**: `locations` (confirmed from location module)

### Task 2: Run ALTER TABLE to add column to live DB

<read_first>
- core/database/db_connection.py
- modules/user/model/user_model.py (just updated)
</read_first>

<action>
Create a one-shot migration script `core/database/add_region_id_to_users.py`:

```python
"""One-shot migration: adds region_id column to users table."""
import sys
import os

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.dirname(__file__))))

from core.database.db_connection import engine
from sqlalchemy import text

def run():
    with engine.connect() as conn:
        # Check if column already exists
        result = conn.execute(text("""
            SELECT column_name
            FROM information_schema.columns
            WHERE table_name = 'users' AND column_name = 'region_id'
        """))
        if result.fetchone():
            print("Column region_id already exists on users table — skipping.")
            return

        conn.execute(text("""
            ALTER TABLE users
            ADD COLUMN region_id INTEGER REFERENCES locations(id)
        """))
        conn.commit()
        print("SUCCESS: region_id column added to users table.")

if __name__ == "__main__":
    run()
```

Then execute it:
```bash
cd backend && python core/database/add_region_id_to_users.py
```
</action>
